# Roadmap

The roadmap is ordered by proof, not ambition. A phase advances when the preceding user outcome works reliably.

## v0.1 — Prove the preflight loop

- Compile common explicit constraints from pasted text
- Let users inspect and correct the rule plan
- Run local file metadata and plain-text checks
- Distinguish pass, fail, review, and skipped
- Export reports and reusable packs
- Ship assignment and creator demos

## v0.2 — Broaden real file coverage

- PDF text and page inspection
- DOCX structure and text inspection
- Image dimensions and metadata
- Stronger requirement parsing fixtures
- Community pack gallery stored in the repository

## v0.3 — Integrate where work happens

- Headless CLI backed by the proven core
- GitHub Action for release and submission folders
- Shareable static HTML reports
- Documented checker contribution API

## Later, only with evidence

- Optional local or remote semantic model adapter
- Approved copy-on-write repairs
- Browser extension for webpage briefs
- Editor integrations
- Hosted collaboration

These are intentionally uncommitted. Each requires demand, a security design, and maintenance capacity.
